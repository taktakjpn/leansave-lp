LeanSave の利用条件

最終更新日：2026年5月5日
バージョン：1.0

第1条（サービス概要）

LeanSave（以下「本サービス」）は、遠藤拓哉（以下「当方」）が提供する iOS 向け食事記録 / 健康管理アプリケーションです。本サービスは、食事写真の AI 解析、PFC バランス / カロリー / 体重トラッキング、30 日 / 90 日トレンド分析等の機能を提供します。

第2条（アカウント登録）

  1. 本サービスを利用するには、Apple サインイン または Google サインインによるアカウント登録が必要です。
  2. ユーザーは登録時に、本規約および別途定めるプライバシーポリシーに同意するものとします。
  3. ユーザーは登録情報の正確性に責任を負い、不正確な情報による不利益はユーザー負担となります 。
  4. 未成年者が本サービスを利用する場合は、親権者その他法定代理人の同意を得たうえで利用するも のとします。

第3条(AI 解析の注意事項)

  1. 本サービスの AI 解析機能は、食事写真から栄養素(PFC / カロリー)を推定する技術であり、結果 は推定値であって正確性を保証するものではありません。
  2. AI 解析結果には誤差が生じることがあります。重要な健康管理判断には、栄養士 / 医師 / 信頼できる栄養データベース等の専門情報を併用してください。
  3. AI 解析リクエストには通信が発生し、Cloudflare Worker(Cloudflare 社)を経由して Anthropic 社の Claude API へ送信されます。

第4条(医療行為 / 栄養指導との関係)

  1. 本サービスは医療行為 / 栄養指導 / 診断 / 治療 / 処方を行うものではありません。
  2. 本サービスは健康増進 / 自己管理を目的とした情報提供ツールであり、特定の疾患の治療 / 予防 / 診断を保証するものではありません。
  3. 持病をお持ちの方、妊娠中の方、医師の食事指導を受けている方は、本サービスの情報のみで判断 せず、医療従事者にご相談ください。

第5条(食事写真 / 入力データの扱い)

  1. ユーザーが撮影 / 選択した食事写真および入力した食事データは、AI 解析処理に利用されます。
  2. 食事写真の取り扱いの詳細は、当方プライバシーポリシーに記載のとおりです。
  3. ユーザーは本サービスにアップロードする情報について、第三者の権利(肖像権 / 著作権等)を侵害しないことを保証するものとします。

第6条(サブスクリプション:LeanSave Pro)

  1. LeanSave Pro は、当方が提供する有料サブスクリプションサービスです。
  2. 提供内容:
    • AI 解析の利用回数制限解除(Free ユーザーは 1 日 5 回まで)
    • 統計 / 体重ページの 30 日 / 90 日長期トレンド分析
    • LeanSave Pro 専用 UI
  3. 契約形態:月額プランおよび年額プラン(詳細はアプリ内 Paywall を参照)
  4. 無料トライアルを提供する場合、その期間、対象プラン、終了後の課金条件は、アプリ内 Paywall または App Store 上に表示します。
  5. 将来的に、サービス改善のため、サブスクリプション状態を当方サーバーに保存する場合がありま す。

第7条(料金 / 自動更新 / 解約)

  1. LeanSave Pro の料金は、アプリ内 Paywall および App Store Connect に表示される金額とし、Apple App Store(StoreKit)を通じて決済されます。
  2. 自動更新:LeanSave Pro のサブスクリプションは自動更新されます。契約期間終了の 24 時間前までに Apple ID のサブスクリプション管理画面で解約しない限り、同期間で自動的に更新され、Apple ID に登録された決済方法に課金されます。
  3. 解約方法:解約は iOS の「設定 > Apple ID > サブスクリプション > LeanSave Pro」からユーザー自身で行うものとします。
  4. アプリ削除と解約:本アプリを削除しただけではサブスクリプションは解約され ません。サブスクリプションの解約は、上記のとおり Apple ID のサブスクリプション管理画面で行ってください。
  5. 解約・返金・請求管理:解約、返金、請求の管理はすべて Apple 社のシステム上で行われます。当方はユーザーに代わって Apple ID 上の解約操作を行うことはできません。
  6. 無料期間中の解約:無料トライアル期間中の解約は課金が発生しません。
  7. 返金:既に課金された期間分の返金は、原則として行われません。返金について の判断は Apple 社の方針に従います。
  8. 返金申請窓口:返金申請は Apple 社の以下ページから行ってください。
    https://support.apple.com/ja-jp/HT204084
